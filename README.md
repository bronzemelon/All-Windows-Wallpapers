# All-Windows-Wallpapers

Contains every single wallpaper from various Windows versions

Wallpapers can be downloaded from [Microsoft](https://support.microsoft.com/en-us/windows/windows-themes-94880287-6046-1d35-6d2f-35dee759701e) or [Ultimate Wallpaper pack](https://www.deviantart.com/windowsaesthetics/art/Ultimate-Windows-Wallpaper-Pack-942163195)
